# План развития CADCraftGOST

Цель: реализовать перечисленные возможности поэтапно, не считать весь план выполненным по завершении отдельного этапа. Это собственная реализация по публичным требованиям, не копирование кода, библиотек оформлений или закрытых ресурсов КОМПАС-3D.

## Состояние плана

Все семь этапов ниже реализованы и прошли приёмку в указанной области поддержки.
Одна реализация команд обслуживает диалоги GUI, CLI и MCP. Это не заявление
о полном функциональном равенстве КОМПАС-3D или сертификации по всей ЕСКД.

- [x] Геометрическое ядро замкнутых многогранных тел для видов и плоских сечений.
- [x] Проецирование и удаление скрытых линий, приоритет видимых совпадающих контуров.
- [x] Ассоциативные виды, разрезы и устойчивые ссылки размеров на вершины/пересечения рёбер.

Ядро этого этапа — многогранное, не аналог аналитического твердотельного ядра КОМПАС:
нет NURBS/ACIS, булевых операций и автоматической аппроксимации кривых.
Пределы и правила обмена перечислены в [руководстве ГОСТ](gost.md).
Приёмка интерфейса, PDF и повторного открытия DXF завершена для реализованных
сценариев. Расширение области поддержки требует собственной проверки.

## Приёмка каждого этапа
- Одна реализация команд для GUI, CLI, скриптов и MCP; программные вызовы не открывают диалоги.
- Проверяемое поведение без заглушек, фиктивных результатов и молчаливой потери данных.
- Undo/redo, сохранение и повторное открытие DXF, корректный PDF, ограничение ресурсов и отказ на некорректном вводе.
- Проверка изменённого интерфейса в работающем приложении.
- Регрессионные тесты для выявленных ошибок и неочевидных потребительских сценариев; документация фактических ограничений.

### Результаты приёмки
- `cargo test --locked -p cadcraft-engine --lib cmd::gost`: 81 тест пройден.
- `cargo test --locked -p cadcraft-geom --lib drafting3d`: 5 тестов пройдено.
- `cargo clippy --locked -p cadcraft-engine -p cadcraft-ui-egui --lib -- -D warnings`: без предупреждений.
- `cargo build --locked -p cadcraft -p cadcraft-cli`: настольное приложение и CLI собраны.
- В работающем приложении проверены диалоги, создание обозначений, требований,
  спецификации и позиции, тела, вида, разреза и размера; загрузка и применение
  сохранённой сетки и разреза.
- Проверочный лист A3 экспортирован в PDF; двухстраничная спецификация A4
  проверена визуально с формами 2/2а, заголовками, строками и нумерацией.
- Изменение длины тела 60→70 перестроило вид, разрез и оба размера,
  включая истинный 3D-размер в изометрии; Undo восстановил 60.
  Изменение через CLI, сохранение DXF и открытие результата в GUI сохранили 70,
  требования, позиции и обе страницы спецификации.
- В этом сценарии нормоконтроль вернул 0 ошибок и 6 предупреждений об областях
  вне геометрического анализа; это **не** положительное заключение о соответствии.

Настройка установщиков через GitHub Actions остаётся отдельной задачей и ждёт отдельной команды владельца.
